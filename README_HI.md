# 🧠 ज्ञान मानचित्र

स्थानीय LLM द्वारा संचालित इंटरैक्टिव ज्ञान वृक्ष जनरेटर।

## विशेषताएँ

- 🌳 स्थानीय LLM (LM Studio) के माध्यम से ज्ञान वृक्ष बनाएँ
- 🔍 अद्यतन जानकारी के लिए वेब खोज
- 🎨 इंटरैक्टिव D3.js विज़ुअलाइज़ेशन
- 📝 प्रत्येक विषय के लिए क्विज़ और सारांश
- 🌍 बहुभाषी समर्थन (6 भाषाएँ)

## स्थापना

1. रिपॉज़िटरी क्लोन करें:
```bash
git clone https://github.com/CaBaGG4811/knowledge-graph.git
```

2. प्रोजेक्ट फ़ोल्डर में जाएँ:
```bash
cd knowledge-graph/server
```

3. निर्भरताएँ स्थापित करें:
```bash
npm install
```

4. सर्वर शुरू करें:
```bash
npm start
```

5. ब्राउज़र में खोलें: http://localhost:3000

## सेटिंग्स

आप सेटिंग्स में LLM सर्वर का URL और मॉडल कॉन्फ़िगर कर सकते हैं।
