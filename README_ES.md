# 🧠 Mapa de Conocimientos

Generador interactivo de árboles de conocimiento impulsado por LLM local.

## Características

- 🌳 Genera árboles de conocimiento a través de LLM local (LM Studio)
- 🔍 Búsqueda web para información actualizada
- 🎨 Visualización interactiva con D3.js
- 📝 Cuestionarios y resúmenes por tema
- 🌍 Soporte multilingüe (6 idiomas)

## Instalación

1. Clona el repositorio:
```bash
git clone https://github.com/CaBaGG4811/knowledge-graph.git
```

2. Navega a la carpeta del proyecto:
```bash
cd knowledge-graph/server
```

3. Instala las dependencias:
```bash
npm install
```

4. Inicia el servidor:
```bash
npm start
```

5. Abre en el navegador: http://localhost:3000

## Configuración

Puedes configurar la URL y el modelo del servidor LLM en la configuración.
