# 🧠 خريطة المعرفة

مولد تفاعلي لأشجار المعرفة مدعوم oleh LLM محلي.

## الميزات

- 🌳 إنشاء أشجار المعرفة عبر LLM محلي (LM Studio)
- 🔍 بحث الإنترنت للمعلومات المحدثة
- 🎨 تصور تفاعلي مع D3.js
- 📝 اختبارات ومراجعات لكل موضوع
- 🌍 دعم متعدد اللغات (6 لغات)

## التثبيت

1. استنساخ المستودع:
```bash
git clone https://github.com/CaBaGG4811/knowledge-graph.git
```

2. الانتقال إلى مجلد المشروع:
```bash
cd knowledge-graph/server
```

3. تثبيت التبعيات:
```bash
npm install
```

4. تشغيل الخادم:
```bash
npm start
```

5. الفتح في المتصفح: http://localhost:3000

## الإعدادات

يمكنك تكوين عنوان URL ونموذج خادم LLM في الإعدادات.
