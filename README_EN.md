# 🧠 Knowledge Map

Interactive knowledge tree generator powered by local LLM.

## Features

- 🌳 Generate knowledge trees via local LLM (LM Studio)
- 🔍 Web-search for up-to-date information
- 🎨 Interactive D3.js visualization
- 📝 Quizzes and summaries for each topic
- 🌍 Multilingual support (6 languages)

## Installation

1. Clone the repository:
```bash
git clone https://github.com/CaBaGG4811/knowledge-graph.git
```

2. Navigate to the project folder:
```bash
cd knowledge-graph/server
```

3. Install dependencies:
```bash
npm install
```

4. Start the server:
```bash
npm start
```

5. Open in browser: http://localhost:3000

## Settings

You can configure the LLM server URL and model in the settings.
