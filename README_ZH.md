# 🧠 知识图谱

基于本地大语言模型的交互式知识树生成器。

## 功能

- 🌳 通过本地 LLM（LM Studio）生成知识树
- 🔍 网络搜索获取最新信息
- 🎨 交互式 D3.js 可视化
- 📝 每个主题的测验和摘要
- 🌍 多语言支持（6种语言）

## 安装

1. 克隆仓库：
```bash
git clone https://github.com/CaBaGG4811/knowledge-graph.git
```

2. 进入项目文件夹：
```bash
cd knowledge-graph/server
```

3. 安装依赖：
```bash
npm install
```

4. 启动服务器：
```bash
npm start
```

5. 在浏览器中打开：http://localhost:3000

## 设置

可以在设置中配置 LLM 服务器的 URL 和模型。
